What this project is

A non-commercial fan effort to write new C++ source code that compiles to the same machine code as the Civilization V engine, for preservation, study, bug fixing and modding. It is not affiliated with, endorsed by or sponsored by Firaxis Games, 2K or Take-Two Interactive. All trademarks belong to their owners.

What we publish, and what we don't

  • We publish hand-written source code, headers, tooling and progress data (function addresses, sizes, names and status).
  • We do not host, distribute or link to game files, executables, assets, machine code, disassembly or saved games, nor any tools or instructions for getting around copy protection.
  • Nothing here can be played or used in place of the game. Building or using the project requires your own legitimately purchased copy.

Contributor terms

  • You own a legitimate copy of the game and work only from it.
  • You contribute only code you wrote yourself (or produced with tools you directed) and never paste disassembly, game bytes or decompiler output into contributions.
  • You license your contributions to the project under the repository's license.
  • Your work is non-commercial, and you will not use the project to infringe anyone's rights.

Privacy

Signing in with GitHub gives us only your public GitHub login name. We store it, your chosen display name (or anonymity), your claims and results, and a hashed API token. We set one session cookie for signing in and no tracking cookies. Ask us at the contact address to delete your account.
