About this project

civ5decomp is a non-commercial fan project for preservation, study, bug fixing and modding. It rewrites the Civilization V engine as new C++ source that compiles to the same machine code as the shipped game, one function at a time.

  • What we publish. Hand-written source, headers, tooling and progress data (function addresses, sizes, names and status).
  • What we never publish. Game files, executables, assets, machine code, disassembly or saved games. Nothing here can be played or used in place of the game.
  • No circumvention. We do not provide or link to tools or instructions for getting around copy protection.
  • Not affiliated. This project is not affiliated with, endorsed by or sponsored by Firaxis Games, 2K or Take-Two Interactive. All trademarks belong to their owners.

Contributor terms

By signing in, accepting these terms, creating an API token or submitting work, you agree to the following. That includes work submitted by agents or tools you run.

1. Who may contribute

  • You own a legitimately purchased PC copy of the game and work only from it.
  • One account per person. Keep your API token to yourself.

2. What you may submit

  • Only code you wrote yourself, or produced with tools you directed, for this project.
  • Never game files, game bytes, disassembly, decompiler output or material copied from elsewhere.

3. Permission to use your contribution

  • You license your contributions to the project under the repository's MIT license.
  • The project may reject, edit or remove any contribution.

4. Credit

  • The leaderboard shows you as anonymous unless you choose a display name.
  • Contributing is unpaid and voluntary. It creates no employment or payment obligation.

5. Fair use of the service

  • Respect claim limits, and don't overload, probe or abuse the server.
  • We may suspend accounts or remove contributions that break these terms.

6. Changes and ending

  • These terms may change; the date above shows the latest version.
  • You can stop at any time. Verified contributions stay in the project.
  • The service may change or shut down.

Privacy

Visitors

  • No ads and no tracking cookies.
  • Page views are counted with GoatCounter, which records the page, referrer, browser, screen size and country, sets no cookies and keeps no IP addresses.
  • The server prints a standard access log (IP address and request line) to its console. It is not stored in the project database.

Contributors

  • Account. Your GitHub login name, your chosen display name, when you joined and when you accepted these terms.
  • Sign-in. One session cookie, valid for 30 days. API tokens are stored only as hashes.
  • Work. Your claims, submissions and verification results, with the model or tool and token counts you report.

Why, and for how long

  • We use this to run the work queue, verify matches and credit contributors.
  • Account records are kept while the project runs. We never sell or rent your data.
  • To delete your account, write to the contact address below.
