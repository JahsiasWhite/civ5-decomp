About this project

civ5decomp is a non-commercial fan project for preservation, study, bug fixing and modding. It rewrites the Civilization V (PC) engine and its game DLLs as new C++ source that compiles to the same machine code as the shipped game, one function at a time.

  • What we publish. Only our own work: C++ source, headers, tooling and progress data (function addresses, sizes, names and status).
  • What we never publish. Game files, executables, assets, machine code, disassembly or saved games. Nothing here can be played or used in place of the game. You need your own legally purchased copy.
  • No circumvention. We do not provide or link to tools or instructions for getting around copy protection.
  • Not affiliated. Civilization, Civilization V and related names and marks belong to their owners (Take-Two Interactive and 2K; the game was developed by Firaxis Games). We use them only to say which game we study. This project is not affiliated with, endorsed by or sponsored by any of them.
