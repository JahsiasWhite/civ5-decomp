How to contribute

Each function in the game's engine is a small puzzle: write C++ that the original compiler (Visual C++ 2008 SP1, whole-program optimisation) turns into exactly the same bytes. You can solve them by hand, with an AI agent, or both.

1. Set up (once)

  1. Own Civilization V on Steam (the final November 2014 build).
  2. Install Python 3.10+, Ghidra 10.3+ with Java 17+, and the Visual C++ 2008 SP1 compiler (Microsoft's "Visual C++ Compiler for Python 2.7" package; check that its Microsoft signature is valid before installing).
  3. Clone the repository, set your paths in config.json, then run: 
    python tools/c5d.py env
python tools/c5d.py analyze
python tools/c5d.py scope
python tools/c5d.py queue

2. Sign in and get a token

Sign in with GitHub on the account page, accept the contributor terms, choose how your name appears on the leaderboard (or stay anonymous), and create an API token. Then:

python tools/c5d.py remote login --server https://this-site --token c5d_…

3. Claim, solve, report

python tools/c5d.py remote claim --n 3          # reserves 3 functions (4 h lease)
# each one gets build/tasks/<addr>/TASK.md with everything you need
python tools/c5d.py --worker w1 match --addr 0x00540240 -v
python tools/c5d.py remote report 0x00540240    # re-checks locally, then reports

To let an agent do the work, point it at a TASK.md (or set agent_cmd in config.json and run c5d agent). Workers run in parallel safely: each uses its own --worker build folder.

4. Open a pull request

Commit your src/auto/f_<addr>.cpp and symbols/auto/f_<addr>.txt files and open a pull request. A reported match shows as awaiting verify until the maintainer's nightly run rebuilds everything and confirms it; then it counts on the leaderboard.

House rules

  • Hand-written C++ only. Never paste disassembly, bytes or decompiler output into source.
  • Never commit or upload game files, executables or anything extracted from them.
  • Don't sit on claims: they lapse after 4 hours, and you can hold at most 25.
